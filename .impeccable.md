## Design Context

Users: Indonesian operations, HR and managers coordinating worker assignments and travel.
Personality: calm, precise, trustworthy.
Direction approved in conversation: offshore enterprise workforce dashboard based on the supplied visual reference; compact deep-navy MMMS sidebar, pale-blue workspace, global search, color-coded KPI cards, operational charts, dense tables, and structured worker readiness/profile views.
Principles: real API data only; clear error/loading states; labeled forms; keyboard accessibility; responsive navigation; Indonesian UI copy.
